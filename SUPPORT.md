# Support and reporting

These are personal, hobby-maintained projects run by one person. Support is best effort, there is
no response-time commitment, and an issue may be closed or receive no individual response.

Use the affected repository's public issue forms for ordinary bugs, compatibility problems,
feature requests, and documentation corrections. Use its **Security** tab and select **Report a
vulnerability** only for a credible, confidential vulnerability in that project.

See the [personal security reporting policy](SECURITY.md). There is no bug bounty or paid
disclosure program, and no payment, rewards, or swag are offered.
